# Insights — Conclusiones de entrevistas - Christian Ramirez

Lo que puedo concluir con ambas entrevistas es que lo que más les conviene a ambos sería una aplicación web la cual sea responsiva para teléfono, tablet y computadoras. Me estaba inclinando más por algo de escritorio, pero no creo que sea lo más óptimo.

Y lo que más ayudaría de esa aplicación web son las notificaciones: llevar un sistema de notificaciones es la clave para este sistema, donde salten las notificaciones cuando urja llamar a un cliente tal día. Llevar un sistema de recordatorios también sería clave.

Además de eso, una interfaz amigable, para que no termine siendo peor que el excel, donde puedan ver toda la información de sus clientes y que también cuente con sus filtros respectivos. Ya tuve acceso a los famosos excels que utilizan, más o menos ambos usan los mismos datos, pero de todas formas habría que normalizar un formato, y así también de esta forma que ellos se familiaricen con el entorno.
